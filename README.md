# SkillPulse

SkillPulse: Academic Diagnostic & Performance Analytics Dashboard

SkillPulse helps students and instructors track learning progress beyond raw grades by mapping quiz questions to specific topics and generating visual performance analytics.

Problem & Solution

Pain Point: Raw grades do not show what a student actually understands or where they struggle.

Solution: Aggregates assessment data by topic/competency tags to highlight strengths and weak spots for students and classes.

Key Features

Core (Must-Have)

Role Authentication: Separate access for Instructors and Students.

Competency Tagging: Link questions to specific course topics.

Automated Scoring: Record responses and compute scores automatically.

Topic Mastery Calculation: Backend aggregation of accuracy percentages per topic tag.

Analytics (Should-Have)

Visual Dashboards: Interactive bar or radar graphs for student topic mastery.

Instructor Weak Spot Summary: Ranks class topics from lowest to highest average score.

History Filtering: Filter quiz performance by date and topic.

CSV Export: Download mastery metrics for academic recordkeeping.

AI & Predictions (Nice-to-Have)

AI Study Plan: Two-paragraph personalized revision plan for weakest topics.

Exam Readiness: Predictive score modeling based on the historical data.

AI Question Generator: Auto-generates practice questions targeting class weak spots
